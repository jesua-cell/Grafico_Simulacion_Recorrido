# Generador de Recorrido Aleatorio

## Descripción
Este proyecto genera y visualiza gráficamente un recorrido aleatorio utilizando números aleatorios. La representación gráfica permite observar el comportamiento y trayectoria del recorrido generado.

## Tecnologías utilizadas
- **Python 3.x**
- **Matplotlib** - Biblioteca para generación de gráf`icos

# Clonar el repositorio
git clone [URL-del-repositorio]

# Ejecutar el script
